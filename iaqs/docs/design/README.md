# iaqs 设计文档

本目录是 iaqs 的设计交付物（M0）。所有实现以这里为准；与 `src/` 下冻结的接口草稿
冲突时以文档为准，实现阶段同步修代码。

## 已确认决策

| 编号 | 决策 | 结论 | 理由 |
| --- | --- | --- | --- |
| D1 | 版本树深度 | **完整分支 + 合并**（commit DAG、refs、三方合并、冲突标记） | 用户要求「版本树管理」；单机也需要并行线 |
| D2 | 暂存区 | **有 index**（`add` 暂存、`commit` 提交 index） | 支持部分提交；状态区分已暂存/未暂存 |
| D3 | 增量存储 | **v1 就做**（对象层 delta + 数据库层压缩/去重） | 用户要求三件套均属首版 |
| D4 | 提交身份 | **不记录作者**（无 user.name/user.email/签名） | 单机单人，身份无意义 |
| D5 | 语言/构建 | C++20 + CMake + Ninja，**零第三方依赖** | 机器无 zlib；自研格式与算法可控可移植 |
| D6 | 文本处理 | 全链路**按字节**；diff/合并按行（保留 `\r`） | 任意编码与二进制安全 |
| D7 | 一致性 | 跨进程锁 + **数据库事务/WAL** 保证原子性 | 单写者场景下 DB 事务即提交原子性 |
| D8 | i18n | 人类可读输出本地化（zh-CN/en），机器格式稳定英文 | 用户明确要求 i18n |
| D9 | 「库」的含义 | **自研关系数据库**，作为 iaqs 内部引擎（最小 SQL 集） | m00127/m00130；不对外做通用数据库产品 |
| D10 | 数据库文件 | **分页 + 分段文件**（8 KiB 页，256 MiB segment 文件），避免单库文件过大被文件系统卡住 | m00140 的补充要求；DB 可增长到 TB 级 |
| D11 | 加密 | **加密库**：数据页、索引页、WAL、元数据全部加密；密码解锁 | m00132/m00140 |
| D12 | 大文件 | BLOB 以 1 MiB 内容寻址分块 + 流式读写；**单文件目标 1 TB** | m00140 的补充要求 |
| D13 | 增量存储分层 | **两者结合**：对象层 delta 链（语义增量）+ 数据库层页压缩与分块去重（物理增量） | 用户选择 C |
| D14 | SQL/事务范围 | 最小集：单表 CRUD、主键/二级索引、WAL 崩溃恢复、单写事务；无 JOIN/聚合/MVCC | 内部引擎，够 iaqs 使用即可 |

## 版本与兼容

- 磁盘格式带版本标识：数据库 MANIFEST `IAQSDB1`，页信封 `IAQSPG1`，delta `IAQSD1`，
  对象逻辑格式见 01 文档。
- 读到不认识的版本直接报「需要更新版本的 iaqs」，不做猜测。
- 决策变更时先改本文件决策表，再改对应设计文档，最后改代码。
