seIDE

An IDE whose project state is a board: cards on an infinite plane, links between them, and no tabs to lose your place in.

Card kinds

  • editor — one file, coloured by a descriptor
  • runner — a command, its output, its exit code
  • files — what is in this folder
  • project — what is in this project, and what is open in it
  • sheet — structured state, no text
  • note — prose

Press & to link two cards, or Esc to stop a run. Angles are harmless here: 1 < 2 < 3, and &amp; stays an entity.
